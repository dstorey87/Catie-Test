Question packs
PractiseTests
{{ p.name }}{{ p.meta }}
A pack is a JSON list using the same fields as the exported bank (question, options ×4, correctIndex, explanation, ruleRef, topic 1–14). Questions you write or have a licence for can be loaded here, then switched on or off for practise and tests separately. Packs can also carry a testType field (car, motorcycle, LGV…), so other theory tests drop in later as packs — no redesign needed.
